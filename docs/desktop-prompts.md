# Desktop 提示词库

在聊天框输入 `/prompt`，从命令菜单选择 `prompt`，或输入完整命令后按 Enter，即可打开提示词窗口。

- **最近使用**：显示最近选择的五条提示词。
- **全部提示词**：按创建时间排列，支持搜索名称和正文。
- **创建 Prompt**：在弹出窗口中填写名称与内容，点击“保存 Prompt”。
- **插入正文**：点击提示词名称，其完整内容会追加到唤醒窗口的聊天草稿中，可继续编辑后发送。

名称最长 100 个字符，同名提示词不区分大小写；正文支持多行，最长 100,000 个字符。提示词库最多保存 1,000 条记录。Esc 关闭当前窗口，Tab 在窗口内移动焦点。

提示词保存在当前 DSH Home 的 `desktop-prompts/prompts.json` 中。同一 Home 下的会话共享提示词库。文件以原子写入和跨进程锁保存，读取错误会显示在窗口中。该功能随 Desktop 客户端插件加载，稳定版与 Beta 版均包含此功能。
