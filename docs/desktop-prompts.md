# Desktop 提示词库

在聊天框输入 `/prompt`，输入框上方直接列出已保存的模板。使用鼠标或 ↑ / ↓ 选择，再按 Enter 将完整正文插入聊天框。候选列表按最近使用时间排序，显示名称和正文摘要；选择模板后可继续编辑草稿。

候选列表中的“新建 Prompt 模板”打开模板管理窗口。填写名称和多行正文并保存；在“已保存模板”中可复制任一模板正文、修改名称和正文，或确认删除模板。保存后回到模板列表，可预览正文。重新输入 `/prompt` 时读取最新模板。

创建与修改支持 ⌘ / Ctrl + Enter 保存；已有未保存内容时返回会提供继续编辑和放弃选择。保存失败保留填写内容，加载失败提供重新加载。删除前显示模板名称并要求确认。

名称最长 100 个字符，同名提示词不区分大小写；正文最长 100,000 个字符；最多保存 1,000 条记录。记录保存在当前 DSH Home 的 `desktop-prompts/prompts.json`，由原子写入与跨进程锁保护。

## 交互与验收

面向在 Desktop 聊天中复用指令的用户。提示词是用户编写的纯文本，保存成功以 Host 写入完成为准，插入成功以对应会话输入框出现正文为准。

| 状态 | 可见行为与恢复路径 |
| --- | --- |
| 加载中 | 显示加载反馈，暂停新建和插入 |
| 首次使用 | 显示创建第一条提示词入口 |
| 搜索无结果 | 保留搜索词，可清空或修改 |
| 最近使用为空 | 说明插入后的记录会出现在此处 |
| 读取失败 | 独立错误状态，重新加载；不显示空库结论 |
| 表单无效 | 错误显示在对应字段下方，并聚焦首个无效字段 |
| 保存失败 | 保留名称和正文，可再次保存 |
| 放弃填写 | 先提供继续编辑和放弃并返回 |
| 已保存 | 选中新记录，展示完整正文和保存反馈 |
| 插入完成 | 关闭窗口，保留原草稿和附件，返回输入焦点 |

窗口使用 Desktop 主题配色、系统字体和原生模态焦点约束。窄窗口时列表与预览上下排列，内容独立滚动；减少动态效果偏好下关闭进入动画。通过实际安装 App 验证创建、保存、重开读取、搜索、插入与焦点返回。
